# MSG Gestion

Administration of the Mouvement Garde Suisse, Paroisse Notre-Dame de Lourdes de Yapoma
(Douala): members, cash book, calendar and duty planning, announcements.

- `backend/` — Django REST API + web back-office
- `app/` — Flutter app (Android first, iOS-compatible)
- `design/` — the design reference (Claude Design export)

Start with `RUNNING_LOCALLY.md`. Deployment: `RENDER_STAGING.md`, `RENDER_PRODUCTION.md`.
What's done and what's next: `BETA_CHANGES.md`, `TODOS.md`. Conventions: `CLAUDE.md`.
